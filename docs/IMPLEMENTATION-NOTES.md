# 云端实施记录
本项目为本地、虚构数据、成年用户演示。独立整体验收后才进入目标 Mac 安装与部署验证。

## 验收范围
- 注册、登录、退出、来源校验、登录限流
- 数据库级原子领取和幂等生命周期
- 参与者隐私、协商取消、举报及审计
- 截止清理、七天保留策略、独立维护进程
- 360/390px 完整流程与失败反馈
- 本地启动、备份、隔离恢复、干净构建

## 运行边界
无短信、邮件、支付、提现、地图或公共访问。管理员由本机交互创建；不提供默认管理员。仅生成虚构测试数据，不携带数据库或账户交付。

## 已验证后端（2026-10-10）
Node 24.19.0；Next.js 16.4.0、React 19.3.0、pg 8.23.1、Zod 4.6.5、Argon2 0.45.1、Vitest 5.0.3、Playwright 1.64.0（确切依赖见 lockfile）。
认证、订单、并发与幂等、举报、维护：38 项测试在真实 PostgreSQL 18.4 上通过；TypeScript 检查通过。不是内存数据库或模拟锁。

手机UI：两账户完整流程、360/390px布局、取消确认、空/加载/失败反馈、抢单冲突提示和HTTP安全边界共5项E2E通过。浏览器使用项目内Headless Chromium，截图实际查看过。

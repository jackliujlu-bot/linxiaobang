# 邻小帮第一版产品设计
手机优先、本机运行的邻里小任务演示。

## 功能
注册登录、发布取餐或倒垃圾任务、2 元或 3 元模拟悬赏、领取、送达、发布者确认、协商取消、举报和基础管理。
仅支持已购买餐食的代取，以及袋装普通生活垃圾。交接优先选公共点，不入户。
不涉及危险品、医疗垃圾、药品代购、真实支付、提现、聊天或地图。

## 交互
四入口：首页、发布、订单、我的。单一主色、留白、大按钮，卡片先展示类型、公开区域、截止时间与模拟金额。
发布表单一页完成，公开区域与私密交接说明分开，提交前可复核。
每个金额展示区域标明“演示数据，无实际资金往来”。

## 订单
待接单 → 已接单 → 已送达待确认 → 已完成。
发布者不能接自己的单；待接单可取消，已接单取消需对方同意或管理员处理。
未接单超过截止时间自动过期，已接单逾期不自动完成。
双方纠纷暂停模拟结算；旁观者举报不直接冻结订单。

## 数据与安全
PostgreSQL 事务保证只有一人领取成功。幂等键防止重试重复结算。
密码采用 Argon2id；会话通过 HttpOnly、SameSite Cookie；服务端检查身份、归属、状态与请求来源。
列表不返回具体门牌、取餐码或私密交接说明。只有发布者与有效当前接单者可读，取消立即撤销接单者读取权。
管理员通过案件访问并审计。普通结束订单七天后清理私密说明，未决案件保留至处理完毕。

## 试用边界
仅本机、成年用户、虚构数据。年龄声明不是身份核验。
本地演示不代表可公开运营；公网、真实支付与真实资料均需另外设计和审查。

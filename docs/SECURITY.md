# 本地演示安全边界
此版本只适用于一个可信操作系统用户控制的本机。桌面浏览器通过 127.0.0.1 使用，所有内容必须是虚构样例。

- PostgreSQL 事务与订单行锁串行化状态变化。幂等键按用户划分，键重复但目标/动作不同报冲突。
- 同一订单的取消、确认、管理员处理与维护清理共同使用数据库锁，状态与模拟金额同事务变更。
- Cookie 不进入页面 JSON；数据库只保存随机令牌的 SHA-256 摘要。HttpOnly、SameSite=Strict，明确检查 Origin 与自定义请求头。
- 私密说明与公开订单分表存储；订单列表和幂等缓存不保存说明。只有发布者和仍有效的当前接单者可读。管理员必须通过案件入口访问并留下审计。
- 已结束订单的说明在七天后清理；尚有未决举报/纠纷的订单继续保留，直到处理后可清理。
- 没有默认管理员。管理员只能在持有本地数据库连接的终端初始化。管理员角色由数据库身份查询给出，不信任浏览器传入的角色。
- 不记录登录密码、会话令牌、私密说明、数据库连接 URL 或完整请求体。

## 仍不适合公网
本地年龄声明不等于年龄核验。登录限流不是完整的公网滥用防护；仍需邀请码、分布式来源限流、注册限制、安全审计、HTTPS、备份策略和正式隐私告知。不要修改监听地址以绕过此边界。
